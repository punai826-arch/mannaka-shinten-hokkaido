# まんなか新店 北海道（PoC）

離れて住む2〜4人の「まんなか」の市町で、開店3年以内の新しいお店を探す地図です。試作版のため、検索エンジンには載せていません（noindex）。

- お店のデータ：厚生労働省「食品衛生申請等システム」のオープンデータを加工して作成
- 地図：© OpenFreeMap © OpenMapTiles © OpenStreetMap contributors
- 移動時間：OSRM（OpenStreetMap）による車の所要時間の目安
- リンク（Instagram・公式サイト・食べログ）は自動で紐づけたものを含みます。写真や口コミは掲載していません
- 誤りのお知らせは Issues へ
